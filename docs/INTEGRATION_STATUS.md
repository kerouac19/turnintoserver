# Apple Silicon 功能整合状态

开发分支：`codex/apple-silicon-utils`；基线：`21e307a`；目标：arm64、macOS 13+。

## 已实现

- 独立开发 Bundle ID、支持目录、历史记录、socket、更新目录和 sudoers 名称。开发版不读取原版遗留路由 plist；路由归属记录网络服务、目标、掩码和网关，无归属的启动关闭不执行网络查询或写入，外部冲突路由保留。
- 外接屏菜单、命令层最后屏保护、禁止内建屏关闭、系统实际状态枚举，以及 0/250/750/1500/3000 ms 的有限重查。状态未稳定时禁止继续关屏；硬件通知独立于菜单生命周期。
- 多屏黑色/保留画面遮罩、Esc 与鼠标解锁、真实鼠标抬起等待和超时、common run-loop modes 下独立的 100 ms 健康监测、启动双重校验，以及会话/锁屏/睡眠清理。未引入 Vorssaint 的其他键鼠模块。
- 协调现有快捷键、MCP 引起的电源变化、合盖、睡眠、唤醒和退出；重复的开盖读数不会结束清洁。异步调暗后发现已开盖会补做亮度恢复。
- 打包用户级 LaunchAgent，持久记录电源和亮度恢复租约；不将其他来源的 `SleepDisabled` 状态直接接管为本应用 Server Mode。心跳首次失联后停止续租，旧请求不能干扰新会话；持有租约时避免 App Nap 导致误判。
- 本地构建/测试脚本及第三方来源、许可证记录。
- 独立 Release 构建、版本/build 参数、ad-hoc / Developer ID 模式、LaunchAgent 与签名校验、公证与票据装订脚本、ZIP / SHA-256，以及接收者安装文档。命令见 [RELEASING.md](../RELEASING.md)。

在当前受限执行环境中构建：

```sh
COMPILER_SUBPROCESS_SANDBOX=NO ./scripts/build-dev.sh
```

普通开发机可直接运行 `./scripts/build-dev.sh`。编译器子进程选项只作用于本次命令，不写入工程配置。产物路径为 `build-dev/Build/Products/Debug/turnintoserver.app`。

固定签名的真机验证使用：

```sh
SIGN_IDENTITY='Your stable code-signing identity' ./scripts/build-dev.sh --signed
```

自动化执行环境没有找到有效的代码签名身份。本地 ad-hoc 签名可验证编译、包结构和签名完整性，但不能替代固定签名的辅助功能/后台项验收。代理执行的检查仅运行了无 GUI 的 MCP 初始化，没有启动菜单栏 App，没有改变真实显示器、输入拦截、sudoers、电源状态或后台项注册。用户随后已实际运行开发包，并反馈功能正常。

## 尚待真机验收

实际启动和用户已试用的功能已获得正向确认；以下专项仍需逐项验收，用户的总体反馈不作为这些场景全部通过的记录。

- 单屏/多屏、切换时热插拔、移除最后屏、合盖状态变化、全屏/Spaces 中两种遮罩及权限丢失。
- 实际睡眠唤醒、接电/电池切换、定时结束、正常退出、强制结束 GUI、看护重启和开盖后的亮度恢复。

这些项目未完成前，不能称为已验收的发行版。M0 的固定签名门槛及 M1–M4 的真机验收仍未关闭。开发版禁用上游更新；正式更新交接、公证、最终应用身份及上游授权仍属于发行前工作。重新构建正在使用的开发包前，应先关闭其 Server Mode 并退出 App，以完成恢复和后台项注销。
